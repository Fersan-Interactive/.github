# Security policy

Report a suspected vulnerability in any Fersan Interactive product, site, service or repository privately to
[security@fersaninteractive.com](mailto:security@fersaninteractive.com), in Portuguese or English. Do not open a public
issue, pull request or discussion about it.

Describe what is affected, how to reproduce the problem and what it allows. For the website, the terms of use also set
out the good-faith rules for testing: [English](https://fersaninteractive.com/en/terms/#reporting-vulnerabilities) ·
[Português](https://fersaninteractive.com/pt-br/terms/#relato-de-vulnerabilidades).
